# homebrew-openconnectmenu

Homebrew tap for [OpenConnectMenu](https://github.com/LeJeko/OpenConnectMenu),
a macOS menu-bar client for openconnect VPN connections.

```bash
brew install --cask LeJeko/openconnectmenu/openconnectmenu
```

This installs the signed and notarized installer package and, as a dependency,
the `openconnect` formula.
